# 📊 Portafolio de Análisis de Datos y Prácticas en Git

Repositorio personal dedicado a documentar mi aprendizaje en control de versiones, visualización y proyectos analíticos.

## 📂 Estructura del Repositorio
- `data/` : Contiene conjuntos de datos de prueba y datasets mock para prácticas.
- `scripts/` : Almacena códigos y scripts de análisis en Python / R.
- `index.html` : Archivo principal del sitio web publicado en GitHub Pages.

## 🚀 Tecnologías y Herramientas
- Git y GitHub Desktop
- HTML5 / CSS3
- Python / Análisis estadístico
